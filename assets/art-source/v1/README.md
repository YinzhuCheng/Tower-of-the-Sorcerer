# Art source masters — v1

High-resolution authoring assets for the 2026-08-30 enemy-and-boss art pack.

- `portrait-master/` — 50 transparent PNG masters, 1024×1536.
- `map-master/` — 50 transparent PNG masters, 1024×1024.
- Runtime derivatives live separately in `public/assets/anime/portraits/v1/` and `public/assets/anime/enemies/v1/`.

These files are source assets only: do not import them into the browser runtime or build output. Regenerate the runtime WebP derivatives when updating a master.
