# Gal Layer 构图卡

| 层级 | 比例/位置 | 目的 |
| --- | --- | --- |
| 背景 | 全屏 16:9 | 只承载场景与气氛，不承载可读文字 |
| 左右立绘 | 宽度各 42%，底部在对话框上沿之上 | 对话角色保持全身，当前说话者高亮、听者压暗 |
| 文本框 | 底部约 28.5% | 固定为单一可读区，永不滚动整个舞台 |
| 姓名牌/头像 | 文本框左上沿 | 姓名、头像、表情状态的视觉锚点 |
| 控制条 | 顶部右侧 | 历史、自动、快进、隐藏、跳过；不遮挡文本 |

剧情只挂载到 `#gal-root`。战斗、背包、图鉴等继续使用常规魔塔弹窗 `#modal-root`。
