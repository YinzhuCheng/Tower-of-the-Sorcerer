# Tower GAL 美术统一设计包 · GAL-SIMPLE-1.2 B1 完成版

本包重新建立GAL美术的权威起点。魔塔地图、敌人战斗形象、物品与地图机制素材保留，不在本轮重绘范围。

## 当前工作流

`文字定稿 → 三视图 → 服饰/武器/物件细节板 → 表情表 → 透明立绘 → 场景卡 → CG布局稿 → CG身份稿 → 最终CG`

每一步只能引用前面已经通过QA的资料。旧图只能帮助辨认角色，不能直接作为服装和物件的最终依据。

## 单张CG固定参考顺序

1. 场景中第一位角色三视图；
2. 第一位角色细节板；
3. 后续角色按同样顺序排列；
4. 场景专用物件板；
5. 表情表；
6. 新版透明立绘；
7. 最多两张已验收的新CG作为脸部与渲染锚点；
8. 环境设计图。

每张图都要保存实际参考文件的相对路径、SHA-256、输入顺序、完整提示词、输出SHA-256和QA结论。任一必要参考缺失时，暂停该CG并先补参考。
