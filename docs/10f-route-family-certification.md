# 10F 路线族证书

状态：**数值阶段的发布门槛**。本证书不修改已冻结的房间、门卡、关键
Boss、关键宝物或楼梯；它只验证这些固定内容之上仍存在足够不同的可玩解。

## 为什么不用“标准路线胜率”

固定购买循环只是快速发现候选的启发式，不是玩家能力模型，也不是发布
目标。一条失败的循环只能说明该循环不适合当前局面，不能说明游戏不可玩。

`certify:demo10:routes` 以一组购买节奏、圣辉取得时机和后期推进偏好作为
**发现种子**，再把每一条成功路线交给 `engine.js` 重放。最终按实际游戏中
发生的决定归类，完全不按种子名称计数。

## 当前阻塞条件

至少需要 3 条引擎重放成功的路线族；任意两条在下列三项中至少相差两项：

1. 是否进入 F8 双守卫宝库并取得 `Dual`；
2. 圣辉是在早期、中期还是晚期取得；
3. 实际商店购买构成是均衡、偏攻击、偏生命或偏防御。

每条路线的最低战斗余量还必须落在 4%–25%：低于下限表示脆弱的偶然解，
高于上限表示这组路线已把硬模式跑成了碾压。

当前 288 个发现种子产生 60 条可重放胜利记录、51 条难度窗口内候选，并折叠
为 22 个实际路线族。被选中的三条路线不是唯一正确答案，而是发布时必须保留
的多样性下限。

运行：`npm run certify:demo10:routes`。
