# 10F 单店制数值回归（2026-08-30）

状态：**已完成并写入生产构建。**

这不是一次拓扑修改。F1–F10 的房间、卡门、楼梯、核心持有者、关键遗物与 Boss
群已先通过空间和卡片状态图验收；本轮只调整 F3–F4 的六种普通敌人，使它们成为从
早期双核心到 F5 唯一商店的过渡层。

## 固定结果

- F5 商店从下楼入口存在无战斗路径；它不能被“必须先打败本层怪物才可用”的循环依赖封死。
- F3/F4 六种普通敌人的桥接档由
  `DEMO10_SINGLE_SHOP_EARLY_RAMP` 固定；没有改动 Boss、门卡、楼梯、核心、关键遗物或
  商店倍率。
- 发布证据是 `atk → def → hp`、立即 Holy、guardian-first 的 198 步权威引擎回放。
  最低战斗余量为 **11.79%**，处于 4%–20% 的硬模式窗口。
- 固定六条简单购买循环不是发布门槛；它们仅是诊断。发布所需的是至少一条可回放的
  合法解。当前路线族扫描仍找到了 65 条可回放胜利、14 个不同玩家决策族。

## 可复现的受约束扫描

```bash
npm run rebase:demo10:single-shop
```

脚本扫描 F3 和 F4 普通敌人的两个离散缩放轴。每个候选都：

1. 复核锁定快照，拒绝 Boss、门、卡、楼梯、核心奖励、关键遗物和房间的漂移；
2. 以权威 `engine.js` 回放策略路线；
3. 只接受 4%–20% 余量窗口内的胜利；
4. 以接近 12% 为首要排序，再偏好较高敌方强度。

脚本不写生产数据。生产档仅在上述回放与完整测试通过后手动写入
`src/game/demo-10-floor-hard-mode.js`。
