# Shared campaign interface v1 (implementation checkpoint)

Location: `src/core/campaign.js`; schema implemented; kernel, voyage and story integration tests passing. A legacy entry still shares only the extracted combat function, not yet fully migrated. Do not describe this as the completed three-campaign product.

`createCampaign(spec)` returns an isolated, deeply frozen content context. `initialState`, `dispatch(state,action)`, `preview(state,action)`, `listInteractions`, `projectView`, `serialize`, `deserialize`, `stateHash`, `meets`, `balanced`, `passable`, `entity`, `region` are the public interfaces.

All authoring data is plain JSON-compatible. Stable IDs are authored, not generated by coordinate order. Do not mutate the runtime spec.

## Spec

- `id`, `difficulty`, `version`, `title`
- `regions`: array `{id,title,map: string[],arrival:{x,y},entities:[]}`. `.` is walkable; other glyphs are scenery/blocking terrain. C uses 11×11
- `initial`: `{location:{regionId,x,y},stats:{hp,maxHp,atk,def,gold},resources:{},flags:{},boat?:{dock,cargo,positions:{}}}`
- `goal`: a condition (required)
- Entity: `{id,x,y,title,kind,blocking?,once?,requires?,blockedReason?,effects?,storyId?,interactionAt?}`
- `kind`: `enemy` (+ `enemy:{hp,atk,def,gold,special?,magicPower?}`), `pickup`, `operation`, `shop` (+ `price`), or `anchor` (for transitions and special controls)
- An entity can be interacted with only on the same tile or an orthogonally adjacent tile. Optional `interactionAt:{x,y}` further restricts the operator to one reachable safe adjacent floor tile; use `runtime.inReach(state,id)` rather than duplicating the geometry test. Default `once=true`; completed enemies/collectibles cannot pay twice. Never set enemy/pickup to repeat
- `transitions`: `{id,anchor,title,to,at?,requires?,cost?:{resourceId:integer},effects?,departure?:{from: dockId,to:dockId},storyId?}`. `to:'@dock'` returns from the same ship deck to its current dock. Other `to` values are explicit region IDs
- C `ballast`: `{deckRegion,control,weights:{w1:1,w2:1,w3:2},slots:{L1:-1,L2:-1,C1:0,C2:0,R1:1,R2:1},cargoTorques:{center:0,left:-2,right:2,ashore:0}}`

## Conditions

Arrays mean AND. Objects support `{all:[]}`, `{any:[]}`, `{not:condition}`, `{flag:'id',value?:true}`, `{resource:'id',min:n,reserveUntrueFlags?:['valve1',...]}`, `{stat:'hp',min:n}`, `{cleared:'entityId'}`, `{dock:'C-M03'}`, `{moored:true}`, `{cargo:'left'}`, `{balance:true}`.

For B heat: initial heat=0; the once-only B03 box pickup adds8 and sets `heatBoxOwned`. Main valve costs1 and sets its flag. Optional warm point cost2 checks `{resource:'heat',min:2,reserveUntrueFlags:[all four closed-valve flags]}` and applies resource -2. This reserves remaining required heat without a second consumable system.

For B wedge/works: separate `rootFixed`/`rootWorksDone`/`originalCleared`/`originalWorksDone` flags. Doors/operations use `any` of the correct paired facts. An edge can require rootFixed, while public readiness requires both rootFixed and rootWorksDone. Model the alternate physical path in terrain/entities; do not add a free third edge.

## Effects

`{resources:{id:signedInteger},stats:{hp,maxHp,atk,def,gold},flags:{id: scalar},cargo?:'center'|'left'|'right'|'ashore',moored?:boolean}`. MaxHP increases before healing, as in legacy A. Effects do not teleport the player; only explicit transitions do. Resource or HP invalidation rejects the whole transaction. `cargo` exists only for voyage.

## Actions and immutable transaction results

- `{type:'move',direction:'up'|'down'|'left'|'right'}`
- `{type:'interact',entityId}`
- `{type:'traverse',edgeId}`
- `{type:'moveBallast',weightId,slot}`
- Optional `expectedRevision` makes a stale UI confirmation fail without charge

`dispatch` returns `{ok,state,events,receipt?,reason?}` and never mutates its input. Rejects return the original state. `preview` calls exactly the same reducer on a clone, so costs/eligibility cannot drift. There is no `setFlag` player command. Only reachable authored operations can perform effects.

`events` contain `storyId` references and receipts; a later story-data integration can map these to clean GAL scene JSON. It must not put resource writes in animation/dialogue callbacks. `projectView` exposes region, entity completion, state clone, nearby action previews, and ballast summary. Placeholder rendering is development-only, not final art.

## Save scope

`createSaveRepository(storage,runtime)` scopes slots by campaign+difficulty+rules version+content hash. Loading happens BEFORE writing an autosave. Do not catch and replace malformed saves silently. `restore()` reads before writing and returns `{state,source,presentation,issues,allowAutoSave}`. Corrupt raw bytes are retained under a deterministic backup key. `save(slot,state,presentation?)` stores an atomic optional game+presentation envelope; old raw state saves still load. `createSaveRepository` accepts an optional `validatePresentation` callback. Recovery/envelope/isolation tests pass.

## Worker ownership

Core/solver/C runtime is being implemented by the shared engine worker. B worker may author `src/campaigns/b/` against this contract and add B-only tests; request core extensions rather than copying the kernel. C geometry worker owns the independent spatial contract. Root coordinates old A bootstrap fixes and story JSON integration.
