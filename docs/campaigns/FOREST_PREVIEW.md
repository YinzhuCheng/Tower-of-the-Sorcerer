# B 霜径标准：2D 开发预览

入口 `public/campaigns-b/`；独立构建入口 `dist-b-preview/campaigns-b/`。这是完整标准规则与冻结 GAL 的文字/棋盘开发预览，不是正式森林美术、三难度平衡或浏览器视觉验收结论。

## 构建与检查

```sh
node scripts/build-b-preview.mjs
node scripts/validate-b-preview-build.mjs
node --test test/campaign-kernel.test.js test/campaign-forest.test.js test/campaign-b-story.test.js test/campaign-b-preview.test.js test/campaign-b-browser-wiring.test.js
```

静态包通过显式白名单构建，无外部 CDN、无 A/C 入口、无任何图片文件。相对模块链接允许部署到根目录或子路径。共享核心、B 标准内容、地理与 GAL 源均原样复制。

## 接线边界

- `view.js` 只产生安全路径、当前构筑预判、资源变化和玩家可读施工状态；所有合法性与预演来自同一个共享 kernel
- `preview-session.js` 管理规则状态与纯展示进度：`seenIds`、`queue`、`turnIndex`、`paused`、`storyVersion` 同一次保存写入，读取发生在首次保存前
- 只有 reducer 接受的真实行动及 receipt 可接入行动后 GAL；选回应、快进、返回地图、继续阅读不会修改规则资源
- 无正文但有分支的片段使用独立 UI 选择面板，不把提示算作 858 条冻结正文。暂停后保留未读正文；实际作业已经完成时移除过期的选择，不保留无法完成的旧操作
- 晚期回访暖点后，未完成的最终核对会重新读取当前合法配置；不重用旧暖点 mask。旧裸状态通关存档可补读实际结尾
- 任何一次性改变、战斗或资源消耗均打开具体确认；免费互逆门户与地面移动直接执行。确认持有 expectedRevision，取消、重复点击、刷新以及载入其他存档不会重复扣除
- 键盘、屏幕方向键、地图、安全路径与普通操作同时受剧情和确认屏障约束；剧情选项的“走到现场”只执行安全移动，随后独立确认实际行动
- 森林背景、CG、镜头和地点从 turn.stage 的语义 ID 传给 DOM data hooks。没有图片回退，不借用旧塔背景，也不显示未批准的冬装或远端人物立绘

## 页面信息

30 个 11×11 真实区域，66 条互逆门户；同屏显示生命、攻防、金币、暖脂剩余/四阀必留/自由余量、根楔和公共工程数量。施工清单逐点区分原路清障/施工、侧根固定/施工、人行与公共轻车。全图只展示真实连接，不提供传送。所有安全寻路均调用 runtime.passable，不穿敌人和阻断施工。

## 验证范围

- UI 会话逐步重放全部 16 条冻结证书，每一步前后 hash 保持一致
- 剧情与确认防穿透、取消、重复确认、拒绝、热脂保留、原子保存、读档恢复、坏档保留、容量失败、跨难度/战役/内容隔离
- 纯回应、延期、快进、无正文选择、真实现场接近、回访后方案更新、旧通关档实际结尾
- 真实 app 的 DOM 接线单测覆盖首次渲染、121 地砖、对话、移动、确认取消/重复，以及保存的当前片段。该测试使用 DOM double，不冒称实机浏览器验收
- 静态入口递归模块检查、DOM ID 检查、无外部资源与共享核心逐字节一致

最终视觉/触摸/窄屏验收应在部署后的 Vercel 地址进行；此包未自行发布。建议实机检查 1440×900、1366×768、390×844 与 360×740：完整棋盘、操作区滚动、GAL 长文本与选项、取消确认、刷新及手动读档。
