# 山路把冬天带回家 · B 霜径标准开发预览

运行 `npm run build:preview:b`，输出 `dist-b-preview`，入口 `/campaigns-b/`。本次包含玩家文案与 B07/B09 连续地图材质样板；其他区域仍是开发棋盘。六张固定 SHA 材质不是最终森林场景或 CG，主角仍用明确的占位标记。

## 本次范围

- 开局树心行动只显示当前暖箱维修，不提前泄露后续餐桌、封口与最终维护清单
- 免费对话、有益拾取、免费施工直接执行一次；战斗、花费、不可逆决定和最终收尾仍保留数字预览与确认
- 根路/旧路施工按真实状态区分，剧情弹窗、取消、重复确认和存档恢复不会额外执行动作
- B07/B09 使用冻结的连续地图与六张材质；碰撞仍由原规则决定，不能通过外观绕开敌人
- 23 个受保护规则/正文/证书文件字节不变；16 条证书仍逐步检查状态哈希

`npm run test:preview:b` 覆盖 B 会话、16 条冻结证书、玩家文案、真实 DOM 接线和 B/共享连续地图断言。`npm run check` 保留原主仓完整检查与验证。Vercel 只构建并发布 B 专属输出。

标准方案开发预览，不声称三难度平衡、全地图美术或实机视觉验收完成。正式纹理接缝/比例、移动与触摸、剧情/确认屏障还需在线浏览器验收。详见 `docs/campaigns/FOREST_PREVIEW.md`。
